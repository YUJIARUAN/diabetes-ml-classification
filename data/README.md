# Dataset

This project uses the Early Stage Diabetes Risk Prediction Dataset from the UCI Machine Learning Repository.

Dataset URL: https://archive.ics.uci.edu/dataset/529/early+stage+diabetes+risk+prediction+dataset

The dataset contains 520 observations and 16 input features, including age, gender, and diabetes-related symptoms.

## How to Obtain the Data

1. Download the dataset from the official UCI repository.
2. Prepare the Excel file named `糖尿病数据集.xlsx`.
3. Place the Excel file in the `data/` directory.
4. Run the Python script from the repository root.

The dataset is used for educational machine learning analysis only and is not intended for clinical diagnosis.
